# 후와네 고양이 실사 기준 그림 (canonical appearance references)

이 그림들이 각 고양이 생김새의 기준이다. 새 그림·캐릭터를 만들 때 털색·무늬·눈색·체형을 여기에 맞춘다. These images define how each cat looks. Match coat, markings, eye color and build when drawing them.

- 사람이 보는 페이지: https://fuwa.dad/assets/#ref
- 기계용 목록: https://fuwa.dad/assets/ref/index.json

배경은 투명 PNG. 파일 이름은 `<id>-<방향>.png`, 자세는 `<id>-pose-<자세>.png`. 미리보기(480px WebP)는 같은 폴더의 `s/` 안.

## 후와 (`fuwa`)

장모 회색·베이지 고양이. 목 갈기와 꼬리가 아주 풍성하고 귀 끝에 장식털이 있다. 황록색 눈, 분홍 코, 늘 살짝 시큰둥한 표정.

Long-haired gray-and-beige cat with a big ruff and a huge plume tail, tufted ear tips, yellow-green eyes, pink nose, a slightly grumpy look.

## 슈리 (`shuri`)

갈색 고등어 태비 단모. 귀가 크고 이마에 M자 무늬, 꼬리에 검은 고리 줄(끝은 검정). 황록색 눈, 분홍 코, 날씬한 몸.

Short-haired brown mackerel tabby with large ears, an M mark on the forehead, dark rings along the tail with a black tip, yellow-green eyes, pink nose, slim build.

Short-haired tuxedo cat in charcoal gray (a lighter black) with white muzzle, chest, belly and paws, a small black spot on the lower lip, yellow eyes, black nose.
